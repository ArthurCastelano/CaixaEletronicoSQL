Sistema de Caixa Eletrônico com SQLite

Sobre o Projeto

Este projeto foi desenvolvido como desafio de Backend utilizando C# e SQLite.
O objetivo é simular um caixa eletrônico funcional através de uma aplicação de console,
permitindo que usuários realizem operações bancárias
e que todas as informações sejam armazenadas em um banco de dados local.

Objetivos

O sistema permite realizar as seguintes operações:

Criar contas bancárias
Realizar depósitos
Efetuar saques
Transferir valores entre contas
Consultar saldo
Visualizar histórico de transações
Armazenar todas as informações em banco de dados SQLite

Como Executar

Clone o repositório: git clone 
Abra o projeto no Visual Studio;
Restaure os pacotes NuGet;
Execute a aplicação.
(O banco de dados será utilizado automaticamente).

Tecnologias Utilizadas

C#
.NET
SQLite
Microsoft.Data.Sqlite (NuGet)
Visual Studio
